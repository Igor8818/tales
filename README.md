## 📌 Sobre o Projeto

Este projeto consiste em uma página web moderna, elegante e de alta performance criada para apresentar a trajetória profissional, acadêmica e os serviços jurídicos de **Tales Almeida**. 

O site foi projetado com foco em usabilidade, design responsivo (adaptado perfeitamente para desktops, tablets e smartphones), estética jurídica sóbria combinada a um visual contemporâneo (Dark Theme com detalhes em ciano e tipografia limpa).

---

## 🚀 Funcionalidades

- **🏛️ Apresentação / Home:**
  - Destaque inicial com foto de perfil e síntese profissional.
  - Links diretos para redes sociais (Instagram, LinkedIn) e acesso rápido ao [Currículo Lattes](http://lattes.cnpq.br/4107853619347208).

- **🎓 Perfil Acadêmico e Profissional:**
  - Histórico detalhado de titulações acadêmicas: Mestre pela Universidade Estadual de Santa Cruz (UESC), pós-graduações pela UCAN/ESA Nacional e Faculdade 2 de Julho/CEJAS.
  - Atuação docente na Faculdade Anhanguera e no Centro Universitário de Excelência (UNEX).
  - Cadeira nº 20 da Academia de Letras Jurídicas do Sul da Bahia (ALJUSBA).
  - Experiência prática em advocacia estratégica cível e trabalhista.

- **📚 Galeria de Publicações e Artigos:**
  - Cards interativos com artigos científicos, ensaios e pesquisas publicadas em periódicos reconhecidos (como *JusLaboris/TST*, *Revistas UNIFACS*, *Academia.edu*, entre outros).
  - Links diretos com efeito *hover* para leitura dos textos na íntegra.

- **⚖️ Escritório — Almeida & Korontai Sociedade de Advogados:**
  - Apresentação da sociedade fundada em 2020.
  - Áreas de especialização (Direito Trabalhista, Digital, Cível/Contratual, Securitário, Previdenciário, Penal, etc.).
  - Abrangência de atendimento na Bahia (Itabuna, Ilhéus, Vitória da Conquista, Salvador) e em outros estados.

- **📞 Contato & Atendimento:**
  - Botões para contato direto via WhatsApp (`wa.me`), ligação telefônica e e-mail pré-formatado.

- **📱 Responsividade & Interatividade:**
  - Menu hambúrguer interativo com animação e camada de overlay para dispositivos móveis.
  - Animações suaves de surgimento de conteúdo em rolagem (*Scroll Reveal*) utilizando a **Intersection Observer API**.
  - Rolagem suave (*smooth scrolling*) entre seções.

## 🛠️ Tecnologias Utilizadas

- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estrutura semântica e acessível.
- **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS):**
  - Layouts modernos com **Flexbox** e **CSS Grid**.
  - Variáveis customizadas CSS (`:root`) para consistência de cores e temas.
  - *Media Queries* para suporte completo a múltiplos tamanhos de tela.
  - Tipografia via [Google Fonts (Poppins)](https://fonts.google.com/specimen/Poppins).
- **[JavaScript (Vanilla ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript):**
  - Controle de estado do menu mobile.
  - Implementação de animações com `IntersectionObserver`.
- **[Boxicons](https://boxicons.com/):** Ícones modernos e integrados.

## 💻 Como Visualizar Localmente

Para rodar o projeto em sua máquina local:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Igor8818/tales.git
   ```

2. **Acesse o diretório do projeto:**
   ```bash
   cd tales
   ```

3. **Abra o arquivo `index.html`:**
   - Dê um duplo clique no arquivo `index.html` para abrir diretamente no navegador padrão; ou
   - Se estiver usando o **VS Code**, utilize a extensão [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) clicando em **"Go Live"**.
