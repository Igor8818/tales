# Tales Almeida — Advocacia, Docência & Pesquisa Jurídica

Website institucional e acadêmico oficial do jurista **Tales Almeida Andrade**, sócio do escritório **Almeida & Korontai Sociedade de Advogados**, Professor Universitário de Direito e Membro Imortal da **Academia de Letras Jurídicas do Sul da Bahia (ALJUSBA — Cadeira nº 20)**.

Desenvolvido por **Igor Hagge** ([@igor_hagge](https://github.com/Igor8818)).

## 🚀 Como Executar Localmente

```bash
# Entrar no diretório
cd tales

# Instalar dependências
npm install

# Iniciar servidor local de desenvolvimento
npm run dev
```

---

## 📦 Build para Produção & GitHub Pages

```bash
npm run build
```

O workflow de GitHub Actions integrado (`.github/workflows/deploy.yml`) realiza automaticamente o build e deploy para o GitHub Pages sempre que houver push para o branch `main` ou `master`.
